# Felipe Brenes Portfolio

Portfolio personal desarrollado con HTML, CSS y JavaScript vanilla.

## Estructura

- `index.html`: estructura semantica principal.
- `src/styles/main.css`: estilos, responsive y tokens visuales.
- `src/scripts/main.js`: datos editables y renderizado dinamico.
- `assets/cv.html`: CV editable temporal.

## Desarrollo local

```bash
python -m http.server 5173
```

Abre `http://localhost:5173` en el navegador.

## Personalizacion

Edita el objeto `portfolioData` en `src/scripts/main.js` para cambiar tecnologias,
experiencia, proyectos, formacion y contenido extra.
