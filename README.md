# Felipe Brenes · Portfolio

Portfolio web personal sobre mi, para conocer mi experiencia, formación, contacto y proyectos.

## ✨ Sobre el sitio

- Interfaz adaptable a dispositivos móviles y escritorio.
- Contenido disponible en español e inglés.
- Secciones de tecnologías, experiencia, proyectos y formación.
- Accesos al CV, GitHub, LinkedIn y correo electrónico.
- Desarrollado con HTML, CSS y JavaScript, sin frameworks.

## 🧰 Tecnologías

HTML5 · CSS3 · JavaScript · TypeScript · C# · Java · Python · SQL

## 💻 Ejecutar localmente

No se requieren dependencias. Desde la raíz del repositorio, inicia un servidor local:

```bash
python -m http.server 5173
```

Abre [http://localhost:5173](http://localhost:5173) en el navegador.

## 📁 Estructura

```text
├── assets/             # Imágenes, iconos y CV
├── src/
│   ├── scripts/main.js # Contenido en español e inglés y renderizado
│   └── styles/main.css # Estilos y diseño adaptable
├── index.html
└── README.md
```
